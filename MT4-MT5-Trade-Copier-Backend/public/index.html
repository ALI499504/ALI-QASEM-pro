نسخ فوري للصفقات

⚙️

إدارة مخاطر متقدمة

Fixed Lot، Lot Multiplier، Balance Multiplier، Fixed Balance Multiplier. حدود min/max lot + SL/TP management كامل.

📊

لوحة تحكم + تحليلات

مخططات Balance/PnL، حساب Win Rate، إحصائيات الصفقات، مقاييس أداء الـ clusters.

🔐

أمان احترافي

تشفير RSA+AES هجين لجميع طلبات API. JWT authentication. Rate limiting. Password hashing بـ bcrypt.

📡

WebSocket فوري

تحديثات real-time عبر Socket.IO. تنبيهات open/close/modify. تحديثات حالة الاشتراك والمدفوعات.

💳

مدفوعات كريبتو

تكامل Cryptomus للمدفوعات. اشتراكات شهرية/سنوية. أكواد خصم. نظام affiliate بعمولة 10%.
