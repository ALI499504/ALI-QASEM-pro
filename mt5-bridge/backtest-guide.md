# M.ROBOT — دليل الباك تست الاحترافي على MetaTrader 5

## قبل البدء: تحميل البيانات التاريخية

### الخطوة 0: تحميل البيانات من History Center (مهم جداً!)

1. افتح MT5 Terminal
2. اضغط **F2** لفتح **History Center**
3. ابحث عن **XAUUSD** (أو XAUUSDm حسب بروكرك)
4. حمّل البيانات للفريمات التالية:
   - **M1** (دقيقة) — لآخر 3 سنوات
   - **M5** (5 دقائق) — لآخر 3 سنوات
   - **M15** (15 دقيقة) — لآخر 3 سنوات
   - **H1** (ساعة) — لآخر 3 سنوات
   - **H4** (4 ساعات) — لآخر 3 سنوات
   - **D1** (يومي) — لآخر 5 سنوات
5. اضغط **Download** لكل فريم

> ⚠️ بدون بيانات تاريخية حقيقية، الباك تست سيكون غير دقيق!

## أولاً: تشغيل الباك تست

### الخطوة 1: فتح Strategy Tester

- من MT5، اضغط **Ctrl + R** لفتح نافذة **Strategy Tester**
- أو من القائمة: **View → Strategy Tester**

### الخطوة 2: إعدادات الاختبار

| الإعداد | القيمة المطلوبة |
|---------|-----------------|
| **Expert** | `MROBOT_SMC_Strict` |
| **Symbol** | `XAUUSD` (أو XAUUSDm حسب بروكرك) |
| **Timeframe** | `M15` (فريم 15 دقيقة) |
| **Period** | `2024-01-01` → `2026-10-18` (آخر سنتين) |
| **Modeling** | ✅ **Every tick based on real ticks** |
| **Initial deposit** | `1000 USD` |
| **Leverage** | `1:100` |
| **Optimization** | `Disabled` |

### الخطوة 3: ضبط إعدادات الإكسبيرت

في تبويب **Inputs** (أسفل Strategy Tester)، اضبط:

| المعامل | القيمة | الوصف |
|---------|--------|------|
| RiskPercent | `1.0` | مخاطرة 1% لكل صفقة |
| MinRRRatio | `3.0` | R:R أدنى 1:3 |
| SL_Pips | `50` | وقف الخسارة 5 pips بعد القاع |
| MaxDailyTrades | `5` | أقصى 5 صفقات يومياً |
| MaxDailyLossPct | `3.0` | أقصى خسارة يومية 3% |
| CooldownHours | `4` | 4 ساعات هدوء بعد خسارة |
| UseNewsFilter | `true` | ✅ تفعيل فلتر الأخبار |
| NewsBufferMin | `15` | 15 دقيقة قبل/بعد الخبر |
| MaxHoldHours | `72` | أقصى مدة انتظار 72 ساعة |

### الخطوة 4: بدء الاختبار

1. اضغط **Start** (الزر الأخضر)
2. انتظر حتى ينتهي (قد يستغرق 5-30 دقيقة حسب كمية البيانات)
3. اضغط على تبويب **Graph** لرؤية منحنى الأرباح والتراجع (Drawdown)
4. اضغط على تبويب **Backtest** لرؤية التقرير التفصيلي

## ثانياً: قراءة نتائج الباك تست

### التبويبات المهمة:

| التبويب | ما يعرض |
|---------|---------|
| **Backtest** | تقرير كامل: إجمالي الربح، نسبة النجاح، Profit Factor، Drawdown، عدد الصفقات |
| **Graph** | منحنى الأرباح (Equity Curve) + Drawdown |
| **Journal** | سجل كل صفقة + رسائل الـ EA |
| **Agents** | أداء الـ EA (للتحسين) |

### المؤشرات الحاسمة:

| المؤشر | المستوى المقبول | المستوى الممتاز |
|--------|----------------|----------------|
| **Total Net Profit** | > $0 | > $100 (على $1000) |
| **Profit Factor** | > 1.3 | > 1.8 |
| **Win Rate** | > 35% | > 50% |
| **Max Drawdown** | < 10% | < 5% |
| **Sharpe Ratio** | > 0.3 | > 1.0 |
| **Recovery Factor** | > 2.0 | > 5.0 |

## ثالثاً: دمج الأخبار الاقتصادية

### فلتر الأخبار المدمج:

الـ EA يحتوي على **News Filter** يوقف التداول:
- 15 دقيقة **قبل** أي خبر عالي التأثير
- 15 دقيقة **بعد** أي خبر عالي التأثير

### الأخبار التي يجب مراعاتها:

| الخبر | الموعد التقريبي | التأثير على الذهب |
|------|-----------------|-------------------|
| **NFP** (الوظائف غير الزراعية) | أول جمعة من الشهر، 13:30 | تذبذب عنيف جداً |
| **FOMC** (قرار الفائدة الأمريكية) | كل 6 أسابيع، 19:00 | حركة قوية |
| **CPI** (مؤشر الأسعار) | منتصف الشهر، 13:30 | تذبذب متوسط-عالي |
| **FOMC Minutes** | بعد أسبوعين من القرار | تذبذب متوسط |
| **PPI** | بعد NFP بأسبوع | تذبذب متوسط |

### كيفية تفعيل فلتر أخبار متقدم:

1. أنشئ ملف CSV باسم `MROBOT_NewsFilter.csv` في مجلد `MQL5/Files/`
2. ضع فيه تواريخ الأخبار بهذا الشكل:
   ```
   2024-01-05 13:30,2024-01-05 14:00,NFP,High
   2024-01-31 19:00,2024-01-31 20:30,FOMC,High
   2024-02-13 13:30,2024-02-13 14:00,CPI,High
   ```
3. الـ EA سيقرأ الملف ويتوقف عن التداول خلال هذه الفترات

## خامساً: نصائح ذهبية

### ✅ افعل:

1. **استخدم "Every tick based on real ticks"** دائماً — أعلى دقة ممكنة
2. **حمّل بيانات M1 كاملة** — الباك تست يحتاجها للـ Every tick mode
3. **اختبر على عدة فترات** — لا تعتمد على سنة واحدة فقط
4. **راقب الـ Drawdown** — لو تجاوز 10%، راجع استراتيجية إدارة المخاطر
5. **قارن مع فترة Forward Test** — شغّل الـ EA على حساب تجريبي لمدة أسبوع وقارن النتائج

### ❌ لا تفعل:

1. **لا تستخدم "Open prices only"** — يعطي نتائج مضللة
2. **لا تتجاهل الأخبار** — أكبر خسائر تأتي وقت NFP و FOMC
3. **لا ترفع المخاطرة فوق 1%** — حتى لو الباك تست يظهر أرباح كبيرة
4. **لا تعتمد على Backtest فقط** — اختبر Forward أيضاً
5. **لا تنسَ Slippage و Spread** — الـ EA يتعامل معها تلقائياً في Every tick mode

## خطوات التركيب:

1. انسخ `MROBOT_SMC_Strict.mq5` إلى مجلد MT5:
   - `C:\Users\<USERNAME>\AppData\Roaming\MetaQuotes\Terminal\<TERMINAL_ID>\MQL5\Experts\`
   - أو من MT5: **File → Open Data Folder → MQL5 → Experts**
2. افتح **MetaEditor** (F4 في MT5)
3. افتح الملف واضغط **F7** للترجمة (Compile)
4. لو نجحت الترجمة، ستظهر رسالة "0 errors, 0 warnings"
5. ارجع لـ MT5 → Strategy Tester (Ctrl+R)
6. اختر `MROBOT_SMC_Strict` من قائمة Expert
7. اضبط الإعدادات كما هو موضح أعلاه
8. اضغط **Start** ✓
